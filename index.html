01About

One camera in, 3D out

This project aims to build a system that converts the monocular (single-view) video stream of a standard camera into stereoscopic 3D, without any stereo camera hardware. For each captured frame, a state-of-the-art deep learning model estimates a dense depth map. Using depth-image-based rendering (DIBR), the system then synthesizes separate left-eye and right-eye views, and fills the disoccluded regions that appear after the view shift with inpainting techniques. Temporal smoothing will be applied to reduce flicker between consecutive frames.

The resulting stereo pair is combined into a red–cyan anaglyph image and shown on an ordinary PC monitor, so that the user perceives depth with inexpensive anaglyph glasses. Several recent deep learning based monocular depth estimation methods will be integrated with the camera and compared in terms of depth quality, perceived 3D effect, temporal stability and frame rate (FPS). The outcome is a low-cost 2D-to-3D conversion product that can be used in education, entertainment and video communication.

02Pipeline

From frame to anaglyph

  1. Input

    Camera

    Frames from a USB webcam or laptop camera via OpenCV.

  2. Model

    Depth

    A pretrained monocular network predicts per-pixel depth.

  3. Geometry

    DIBR

    Depth becomes disparity; the frame is warped into L and R views.

  4. Cleanup

    Fill

    Inpainting for holes, temporal smoothing against flicker.

  5. Output

    Anaglyph

    R from the left view, G+B from the right, full screen.
